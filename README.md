# Django-React-Templatetags

A Django library that allows you to easily render and hydrate React (16+) components inside your Django templates, with optional server-side rendering support.

---

## Installation

```bash
pip install git+https://github.com/djangomango/django-react-templatetags.git@0.1.0
```

Or add to your `requirements.txt`:

```txt
git+https://github.com/djangomango/django-react-templatetags.git@0.1.0
```

Add `django_react_templatetags` to your `INSTALLED_APPS` in `settings.py`:

```python
INSTALLED_APPS = [
    ...
    "django_react_templatetags",
    ...
]
```

Add the context processor to `TEMPLATES` in `settings.py`:

```python
TEMPLATES = [
    {
        "OPTIONS": {
            "context_processors": [
                ...
                "django_react_templatetags.context_processors.react_context_processor",
            ],
        },
    },
]
```

## Usage

### 1. Rendering Components in Templates

Load the `react` template tag library and render components:

```html
{% load react %}

<!-- Render a React component with props -->
{% react_render component="UserProfile" prop_name=user.username prop_is_active=user.is_active %}

<!-- Print hydration script before the closing body tag -->
{% react_print %}
```

### 2. Passing Model Data

You can pass models or dictionaries directly as props:

```html
{% react_render component="ProductCard" prop_product=product %}
```

### 3. Client Hydration

Ensure your client-side JavaScript mounts the components generated by `react_render`. Components are rendered with standard data attributes (`data-react-component` and `data-react-props`).

---

## Configuration (Optional)

Configure component settings in `settings.py`:

```python
# Component name prefix (default is empty)
REACT_COMPONENT_PREFIX = ""

# Enable SSR (Server-Side Rendering) endpoint
REACT_RENDER_HOST = "http://localhost:8080/render"
```
